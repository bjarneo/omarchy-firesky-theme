# Firesky

A dark theme inspired by a fire-lit sky for [Omarchy Quattro](https://github.com/omacom/omarchy).

![Firesky preview](preview.png)

## Install

```bash
omarchy theme install https://github.com/bjarneo/omarchy-firesky-theme
```
